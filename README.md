# Web Coursework Project

A simple front-end web application featuring HTML, CSS, and JavaScript.

## Project Structure

- `index.html` - Main landing/home page[cite: 1].
- `pay.html` - Payment page[cite: 1].
- `success.html` - Success confirmation page[cite: 1].
- `css/` - Contains stylesheet files (`style.css`)[cite: 1].
- `images/` - Asset folder containing project images and icons[cite: 1].
- `javascript/` - Contains client-side script logic[cite: 1].

## How to Run Locally

Since this is a static front-end web project, no complex build tools or servers are required.

1. **Clone or Download** this repository to your local machine.
2. **Open the project folder** in your code editor (like VS Code).
3. **Run the project**:
   - Double-click on `index.html` to open it directly in your default web browser.
   - *Alternatively*, if you use VS Code, right-click `index.html` and select **"Open with Live Server"** for a better development experience with hot-reloading.
